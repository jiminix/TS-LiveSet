# TS Playlist Viewer — iPhone

Version web/PWA du Viewer TS Playlist.

Compatible iPhone 13 et versions iOS récentes. Ouvrir la page dans Safari puis utiliser « Partager » → « Sur l’écran d’accueil » pour l’utiliser comme une application.

Fonctions : même code Internet que le Manager, synchronisation automatique, playlist principale, EN COURS, titres désactivés à 50 %, Medley +/- et mode lecture seule.
